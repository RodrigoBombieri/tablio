# Capturas de Tablio

Esta carpeta contiene cuatro capturas PNG de una instancia temporal con datos ficticios:

1. `01-inicio.png`: inicio con el resumen y los módulos.
2. `02-registros.png`: tabla de un módulo, con búsqueda y filtros visibles.
3. `03-importacion.png`: revisión de columnas y datos antes de importar.
4. `04-editar-registro.png`: formulario para editar un registro.

El [`README.md` principal](../../README.md) muestra las cuatro imágenes.

Las capturas se generaron con datos de prueba, sin mostrar contraseñas ni información privada.
